# PGI visual meshes

This directory is reserved for legally redistributable, exact-model visual
meshes converted from verified DH Robotics PGI-140-80/J1/F1 CAD.

No detailed mesh is committed yet: the current official download is gated,
the visible body listing is PGIA/F2 rather than the requested PGI/F1 variant,
and redistribution permission is unresolved. Do not add third-party or
unverified PGIA geometry here.
